A modern, bloat-free WordPress theme designed for high-ranking recipe publishing and food blogs.

== Features ==
* Ultra Clean & Fast: Removed emoji scripts, RSD links, wlwmanifest, and unnecessary headers.
* Built-in Schema.org Recipe JSON-LD for Google Rich Results & Rich Pins.
* Theme & Object Taxonomy: Organize recipes by French cuisine, Recycled pizza, Thanksgiving, etc.
* Downloadable Recipe Files: Instant 1-click printable & PDF recipe generation.
* Mobile-First Responsive Design: Clean typography and interactive ingredient checklists.
* 100% Compatible with WordPress REST API and PinRecipe Scale Engine.

== Installation ==
1. Download the `pinrecipe-culinary.zip` package from your PinRecipe dashboard.
2. In your WordPress Admin, navigate to Appearance -> Themes -> Add New -> Upload Theme.
3. Choose `pinrecipe-culinary.zip` and click Install Now.
4. Click Activate.
5. In PinRecipe dashboard, sync your recipes directly!
